# Apps
## Responsibility
Deployable UI and protocol adapters.
## Boundaries
May call supported application/service contracts; must not read private stores directly.
## Entry points
Each child app owns its package manifest and README.
## I/O and privacy
Inputs and outputs use explicit API/MCP schemas; personal content remains local.
## Tests
Run each app's contract and render tests.
## Ownership
Owner: delivery. Status: supported.
