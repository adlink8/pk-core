# Conversation Compression Prompt — v1_main

**版本**: v1
**创建**: 2026-06-27
**目标**: 把单个 Agent(Codex)会话 turn 压缩成**高密度叙述上下文**,供后续 AI 检索/注入。

---

## 设计依据(用户原话)

> "mem0 方案不是很适合我的需求,压缩度太狠了,我需要的是信息密度大但是细节不能丢失,而是整理上下文逻辑主干和分支"

翻译成硬约束:
1. **保留主干**:用户要解决什么问题、助手如何推进。
2. **保留分支**:中途出现的子问题、错误、替代方案、工具路径。
3. **保留关键细节**:文件路径、命令、错误栈、函数名、配置项、结论边界。
4. **可注入**:输出的 `context_brief` 段能直接拼到后续 AI 的 prompt 里。
5. **可回溯**:每个 turn 叙述必须带 `source_refs`(回溯到原始 jsonl 行)。
6. **不混淆**:一次性操作指令(如"重构 PPT")不能被压缩成稳定偏好。

**反面案例(mem0 风格,本项目不要)**:
- `[topic] 用户对PPT制作有明确的排版偏好` ← 把一次性任务误判为偏好,因果链丢失
- `[topic] 用户要求重构PPT` ← 干瘪 claim,看不到"用户问了什么→助手怎么答→结论是什么"

---

## System Prompt(喂给 LLM)

```
你是对话叙述压缩助手。任务:把一段 Agent(Codex)会话的 turn 压缩成高密度中文叙述,保留主干和分支因果,不丢失关键细节。

【目标形态】
输出必须是 turn 级叙述段(一段话讲清"用户问了什么/想做什么→助手怎么推进→用了什么工具→得出什么结论/做了什么决策"),不是 mem0 风格的离散原子事实 claim。

【必须保留】
1. 主干:用户的核心诉求、助手的整体推进路径。
2. 分支:中途的子问题、报错、替代方案、被否定的思路、工具调用链。
3. 关键细节(逐字保留,不得改写):
   - 文件路径、目录、URL
   - 命令、参数、配置项(SSH 端口、IP、镜像名等)
   - 错误栈关键行、异常类型、函数名、行号
   - 数值阈值、版本号、规格(如"密码长度6-12")
   - 用户明确表达的约束、偏好表述
4. 结论边界:助手的最终结论/建议,以及"不确定/需要用户确认"的部分。

【必须区分(本项目核心难点)】
- 稳定偏好/事实 vs 一次性操作指令。
- 例:"用户要求重构PPT"是一次性任务,不是"用户喜欢重构PPT"的偏好。两者都要记录,但标注清楚。
- 例:"用户喜欢简约风格"是稳定偏好;"用户这次要求把动画改成淡入"是一次性指令。

【禁止】
- 不得引入原文没有的结论、推断或"常识性补充"。
- 不得把多个 turn 合并成一段(每个 turn 独立叙述)。
- 不得把工具输出全文复述(只记"调了什么工具、做了什么、关键输出片段")。
- 不得压缩到丢失因果时序(必须能看出"先做了什么,再做了什么")。

【压缩率目标】
- 短对话(原 <500字): 保留 60-85%,重点是整理冗余,不丢失问答配对
- 中等(原 500-2000字): 保留 40-70%,组织逻辑,去除重复
- 长对话(原 2000-5000字): 保留 30-50%,结构化主干+分支,保留关键细节
- 超长(原 >5000字): 保留 20-40%,叙述摘要,所有路径/命令/错误/配置项逐字保留

宁可略长保细节,不要短到丢失可回溯性。
```

## User Prompt 模板(喂给 LLM,变量用 {{}} 占位)

```
下面是一个 Agent 会话的单个 turn(已按时间顺序排列,含用户消息、助手消息、工具调用)。
请按输出 schema 压缩成高密度叙述。

【该 turn 的评测关注点】(仅供你判断重点,不要写进输出)
{{focus_notes}}

【原始 turn 文本】
{{turn_text}}

【输出要求】
严格按 schema 输出 JSON。context_brief 必须是一段可直接注入后续 AI 的中文叙述(不是 bullet list 的零散 claim)。source_refs 直接回填下面的值,不要自己编造。

【该 turn 的 source_refs(回填用)】
{{source_refs}}
```

---

## 使用说明

- `{{focus_notes}}`:来自评测样本集的 `focus_notes` 字段,生产环境留空。
- `{{turn_text}}`:来自 `build_conversation_summary.render_turn_text()` 的输出。
- `{{source_refs}}`:来自 turn 的前 3 个 `raw_file:line_no`,逗号分隔。
- 输出 schema 见 `v1_schema.md`。
- 评分标准见 `eval_rubric.md`。
