# v1.3 Research Summary

Use the existing local-first services as a tool-only ChatGPT App. Phase 32 exposes the four completed authorities through shared checksum-verifying REST/MCP reads. Phase 33 adds an explicit, bounded orchestration state machine whose writes require checksum-bound confirmation and are replay-safe. Phase 34 standardizes concise summaries, typed errors and evidence drill-down without introducing a widget dependency. Phase 35 proves one-command runtime health plus a real ChatGPT read flow and confirmed low-risk flow.

This preserves the product's core invariant: LLM output is a recommendation candidate; deterministic code owns facts, safety and authorization; the user owns the final decision and every external action.
