# v1.3 Feature Research

## Required

- Unified list/get/explain surfaces for External, Analysis, Pilot and Calibration authorities.
- A bounded `prepare → confirm → generate → decide → observe → calibrate` agent session.
- Concise model-facing results with stable identifiers, limitations and next allowed actions.
- Typed errors, checksum/evidence drill-down, replay-safe writes and live ChatGPT acceptance.

## Deferred

- Rich embedded widget/dashboard.
- Public app submission or stable public hosting.
- Learning/career expansion and any high-risk domain.

## Explicitly excluded

- Automatic external execution, automatic policy promotion, broad crawling, or treating model output as fact/final decision.
