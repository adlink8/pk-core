# Examples
## Responsibility
Minimal supported examples for consuming public search/API contracts.
## Boundaries
Not production orchestration and never a source of shared logic.
## Entry points
Run individual examples with synthetic or explicitly configured local input.
## I/O and privacy
No embedded user paths, credentials or personal fixtures.
## Tests
Import/syntax and consumer contract smoke tests.
## Ownership
Owner: developer-experience. Status: examples; review with contract changes.
