- `docs/retrieval/exam_v2.json` = meta + **v1 的 87 题原样保留（零改动，保证可比）** + **86 道新题**（`origin=v2-20260928`）。
- 新题来源：`docs/retrieval/exam_v2_pool.json`（90 候选，按家族缺口分层采样自 1,860 条 ok 摘要，
  排除 v1 已覆盖会话及其双胞胎），每题由摘要 theme/asks/did/quotes 人工撰写，**86/86 的 gold 直接有 ok 摘要、全部可命中**。
- 兄弟会话标注（答案集上限 gold+3，共并入 15 处）：跨家族 id 十六进制片段（≥10 位）互含=跨通道镜像；

  kimi 同工作区所有 agent 轮次共享同一 session uuid（纯 id 规则一次误并十几个不同任务）、
  Target D 模板化罐头话术簇（纯引语规则误连 9~16 个"双胞胎"）。两簇均已排除并抽验。

## 三、关键发现 1：Jev 裁判在扩大考卷上净负收益

- 全卷裁判改善 14 题 / 帮倒忙 21 题 / 把 gold 踢出重排池 2 题；帮倒忙的 21 题里 15 题是新题。
- v1 子集上裁判仍然正收益（79→81），新题子集上明显负（74→66）。
- 机制（推测，未逐题取证）：新题大量集中在同主题会话密集区（Target D 核算簇、novel-mind GSD 执行、
  grok BATCH 批次），top30 候选池里"看着都相关"的近邻会话多，0.8B 裁判缺乏颗粒度，重排近似洗牌。
- **建议（需另批，属检索服务策略）**：裁判改为 fallback 模式——仅当纯向量 top3 未命中时才启用重排；
  或换更强裁判。v1 式"永远重排"在难考卷上已是负资产。
